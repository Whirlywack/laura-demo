# "Today" is the latest Call, not the calendar date

Every area of the page that says "today" shows the latest Call and its Entries; earlier Calls, rehearsals included, are History. We chose this over the calendar date because the demo is rehearsed several times on the morning it is shown: by date, rehearsal Doses and Wellbeing would pile up and the real Call would open with Doses already taken. Pressing Call now starts a clean Today, and re-running the sample-data script clears rehearsals from History.
