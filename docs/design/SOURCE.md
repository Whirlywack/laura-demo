Copied on 14 Nov 2026 from the Claude Design project "Laura design system" (project id `f7e60674-db28-4a32-aeb1-6b992ae4ca23`). Files are verbatim.

- `readme.md`: the design system's own description. Start here.
- `styles.css`, `tokens/`: colour, type, spacing, radii and motion tokens.
- `components/core/*.jsx`: the eleven components.
- `ui_kits/dashboard/`: the carer dashboard built from those components, with a simulated call.
- `option-15a-approved-mockup.html`: the approved dashboard mockup (option 15a), cut from the project's exploration file.

Not copied: the home page kit (option 14a), guideline specimen pages, type declarations, component prompt notes, the preview loader, the exploration history, and uploads.

The kit's sample data and its simulated call are illustrations. `docs/demo-brief.md` and the spec decide what the page shows and where the data comes from.
