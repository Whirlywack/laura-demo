# Carer dashboard

The page the carer (Povilas) opens for a minute at a time. Source: option 15a in `Laura Directions.dc.html`.

- `index.html` mounts `Dashboard.jsx`.
- Press **Call now** (or → / Space) to play a simulated call. Items arrive every 2.6 s; → or Space steps manually. The call ends 4 s after the last item.
- Three levels: the answer row (large type), the details card (reading size), then the feed and folded rows (quiet).
- The before-call and after-call states were not drawn in the approved mockup; they are derived from it.
