Tick list of errands, each with her words; lives inside the action AnswerCard.

```jsx
<Checklist onToggle={toggle} items={[
  { label: 'Tea', quote: "I'm nearly out of tea. Two bags left.", meta: 'Just now', isNew: true },
  { label: 'Hearing-aid batteries', quote: 'The little round ones.', meta: 'Wed' },
]} />
```

Set `onHighlight={false}` when used on a white card.
